# Focus interview — five questions

Skill-local reference of `context-connect`, Step 5. Ask one question at a time; use a structured question only where there are options (rhythm), free text elsewhere. Write each answer into the focus note (`personal_notes.now` from the provider manifest; default `<plugin_folder>/Now.md`) right away, in `user.language`. Never answer for the user.

| # | Question | Section | Rules |
|---|---|---|---|
| 1 | "What are you working on now — missions, projects, topics? Name them your way; I will link them to the cards." | In progress | match each item to the provider's mission cards (`missions_dir`, names and aliases in its index); found → a link; not found → the text plus "(no card)" and a line for the owner in the to-do note |
| 2 | "What is on hold or postponed?" | On hold | the same matching |
| 3 | "Which open questions do you need to close soon?" | Open questions | no third-party names unless the user gives them; no judgements added |
| 4 | "What is your rhythm — recurring meetings, reports, planning — and how often?" (status meetings per mission · weekly report · sprint planning · quarterly planning · other) | Rhythm | when the weekly report carries numbers, point to the provider's data-source rules (`playbook`) |
| 5 | "Which dates should you keep in mind?" | Dates | one line each: `YYYY-MM-DD — what` |

The note already lists the team's missions from the core; ask which of them are really the user's. After the interview: update `updated:` in its frontmatter, show the note in five to seven lines, ask "anything to fix?". Connector setup is a separate step the user takes later.
